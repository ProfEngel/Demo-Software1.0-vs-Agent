Installationsanleitung (PWA)

  • iPad / iPhone (Safari): Tippe unten bzw. oben auf die Schaltfläche Teilen (Viereck mit Pfeil nach oben) und wähle „Zum Home-Bildschirm“.
  • Android (Chrome / Edge): Tippe auf das Drei-Punkte-Menü und wähle „App installieren“ oder „Zum Startbildschirm hinzufügen“.
  • Windows / Mac (Chrome, Edge, Brave): Klicke im Adressfeld des Browsers auf das Installations-Symbol (Bildschirm mit Pfeil) oder das Dreipunkt-Menü → „App installieren“.
  • Browser-Nutzung: Die App kann jederzeit auch ohne Installation direkt im Browser voll funktionsfähig und offline genutzt werden.
